# Task 4 - Keystroke Visualizer

## Objective
Create a program that demonstrates keyboard event handling by recording keys entered within the application's own window.

## Features
- Detects key presses within the application window.
- Displays the last key pressed.
- Saves key events to a text file.
- Does not capture system-wide keystrokes.

## Technologies Used
- Python 3
- Tkinter

## How to Run

```bash
python keystroke_visualizer.py
```

## Output
A file named `keystrokes.txt` is created containing the keys pressed within the application window.
